## Technologies Used

- HTML5
- CSS3
- Amazon S3
- Amazon CloudFront
- CloudFront Origin Access Control (OAC)
- HTTPS

## AWS Architecture

1. Website files (`index.html`, `style.css`, and images) are stored in Amazon S3.
2. CloudFront retrieves content from the private S3 bucket using Origin Access Control.
3. CloudFront distributes the website and supports secure HTTPS access.
4. CloudFront invalidations help publish updated website files.

## Project Features

- Responsive personal portfolio website
- About, skills, projects, education, and contact sections
- AWS-hosted website deployment
- Secure delivery through CloudFront and a private S3 origin
